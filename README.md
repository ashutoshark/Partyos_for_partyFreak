# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/ashutoshark/Partyos_for_partyFreak.git
```

## Configure Database

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/partyos
spring.datasource.username=root
spring.datasource.password=your_password
```

## Run Application

```bash
mvn spring-boot:run
```
